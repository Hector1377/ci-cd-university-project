## 📋 Project Overview
Educational **CI/CD pipeline** demonstrating modern DevOps practices using GitHub Actions, Docker, and automated testing.

## 🎯 Key Features
- ✅ Automated Testing (Unit, Integration, Linting)
- 🐳 Docker Multi-stage Builds
- 🔄 Complete CI/CD Workflow
- 📦 GitHub Container Registry Publishing
- 🔐 Security Scanning (SAST, DAST, Container)
